PERSONAL PORTFOLIO WEBSITE

Files:
- index.html: website structure
- style.css: colours, layout, responsive styling
- script.js: mobile menu, current year, demo contact form

How to run on your MacBook:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code, or double-click index.html to open it in your browser.
3. Edit index.html to replace the sample content with your real name, college, skills, project details, email, and city.
4. Save changes and refresh the browser.

Note:
The contact form is a front-end demonstration only. It does not send email or store messages on a server.
The skill percentages and project cards are illustrative placeholders; edit them to accurately reflect your own work.
